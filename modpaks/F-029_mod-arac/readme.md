# mod-worgoblin-high-elf
## F-029_mod-arac

### Purpose
To allow any race to be any class.

### Known Issues
- None.

### Considerations
- This version doesn't give all hunters bows and guns at creation, but seeks to retain WotLK starting skills. ARAC combinations get those of similar races.
- Tauren and Draenei normally never start with the Daggers skill, but I made an exception for Rogues.
