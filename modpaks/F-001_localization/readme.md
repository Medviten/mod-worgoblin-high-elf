# mod-worgoblin-high-elf
## F-001_localization

### Features
- Adds localization to appropriate DBC columns for:
  - Korean
  - French
  - German
  - Simp. Chinese
  - Trad. Chinese
  - Spanish (ES)
  - Spanish (MX)
  - Russian

### Known Issues
- Columns are mislabelled in WDBX (e.g. Korean is labelled enGB instead of koKR), which has caused some confusion. Let me know if anything is wrong in the actual client.
